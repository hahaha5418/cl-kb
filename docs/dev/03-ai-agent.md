# 搭建你的第一个 AI 助手（Agent）

## 一句话看懂

普通聊天是「**一问一答**」；Agent（智能体）是给 AI 装上**手和脚**——它能自己查资料、自己调用工具、把一件事办完再来找你。

## 它到底是什么

一个 Agent 由三样东西组成：

1. **大脑**：就是大模型本身，负责**判断下一步该干什么**
2. **工具**：它能调用的外部能力，比如联网搜索、读取文件、发送消息、生成图片
3. **记忆**：记住前面聊过什么，避免每句话都从头开始

工作模式是一个循环：**思考 → 选工具 → 执行 → 看结果 → 再思考**，一直重复到任务完成为止。

> 类比：普通聊天像你问路人一个问题；Agent 像你**雇了个助理**——你说「帮我查一下并整理成表格」，他自己去查、自己做表，做完才回来汇报。

## 零代码做法：用「扣子 Coze」搭一个

完全不用写代码，跟着做：

1. **打开扣子平台**（国内可直接访问），用手机号注册并登录。
2. **点「新建」创建一个智能体**，给它起个名字，比如「每日 AI 简报员」。
3. **在「人设与回复逻辑」里写清楚它的职责**：用大白话说明它是谁、能做什么、不能做什么。这一步决定它聪不聪明。
4. **在「技能」或「插件」区添加能力**：新手先加**联网搜索**和**网页阅读**这两个就够用。
5. **在右侧对话框试聊**，问它一个真实问题，看它会不会自己去搜索。
6. **不满意就改第 3 步的设定**，反复调几次，直到输出稳定。
7. **点「发布」**，选择发布到网页、飞书或公众号，你就得到一个**能分享给别人的 AI 助手**。

> 关键点：**第 3 步的人设描述**是整个 Agent 的灵魂，写得越具体，它表现越好。

## 人设怎么写才有效

按这四段来写，基本不会太差：

- **角色**：「你是一位专注 AI 领域的中文简报编辑」
- **任务**：「每天为用户挑选 3 条最重要的 AI 新闻，各写一句中文摘要」
- **限制**：「**只输出中文**、不许编造事实、无法确定就说『暂无可靠信息』」
- **格式**：「用序号列出，每条不超过 50 字」

## 新手常踩的坑

- **以为 Agent 是更聪明的模型**：不是。它是「**模型 + 工具 + 循环**」，模型本身没变强。
- **工具给太多**：一口气挂十几个插件，它会挑花眼。**先给 1 到 2 个最需要的**。
- **没有停止条件**：它可能不停转圈、反复调用，**既慢又烧钱**。一定要写明「做完就汇报，不要无限重试」。
- **不敢限制它**：明确写「不许编造、不许猜测」能显著减少胡说八道。

## 它不适合什么

- **要求 100% 准确的任务**：Agent 会自己「发挥」，关键结论必须人工核对。
- **一次性的简单问题**：直接问聊天助手更快，没必要搭 Agent。
