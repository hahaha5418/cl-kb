# 把 AI 接到你自己的东西里（API 大白话）

## 一句话看懂

**API 就是「让别人家的 AI 能力，替你干活」的传话筒**——你在网页上聊天是人在操作，API 是让程序替你操作。

## 它到底是什么

把大模型想象成一位**住在云端的顾问**：

- **聊天窗口**：你亲自打开网页，一句一句问他
- **API**：你雇了个助理，按固定格式把问题送过去、把回答带回来

两者的区别只在于「**谁在传话**」。API 是让**程序和程序对话**，所以它能批量处理、能定时执行、能嵌进你自己的表格、网页或机器人里。

> 类比：聊天窗口像你自己去柜台点餐；API 像你给外卖平台下单，系统自动把餐送到你手上。

## 三个必须先懂的词

1. **API Key（密钥）**：相当于**一把专属钥匙**。谁拿到它，谁就能以你的名义调用 AI，并且**花你的钱**。所以千万别发到群里、别贴到公开网页。
2. **请求（Request）**：你发出的那句话，以及附带的设置（用哪个模型、要多长回答）。
3. **返回（Response）**：AI 回给你的内容，通常是一大段结构化文字。

## 不写代码，也能用上 API 的能力

如果你是纯新手，**下面这三条路效果一样，但完全不用碰代码**：

1. **用现成的 AI 平台**：像扣子（Coze）、Dify 这类平台，已经帮你把 API 接好了，你只要填内容、点发布。
2. **用浏览器插件 / 桌面客户端**：很多工具内置了密钥配置界面，填一次就能用。
3. **让 AI 帮你写代码**：把你的需求说清楚，让对话助手生成代码，再让它**逐行解释**给你听。你负责复制粘贴，不懂的地方继续追问。

## 如果你决定自己动手：六步流程

1. **选一家国内能稳定访问的服务商**，用手机号注册账号。
2. **找到「API 密钥」或「开发者设置」页面**，点「创建新密钥」。
3. **立刻把密钥复制保存**到只有你能看到的地方（很多平台只显示这一次）。
4. **确认你有免费额度**。多数平台新用户会送一部分免费调用次数，**先用完免费额度**再考虑付费。
5. **挑一个模型名字**。同一平台会有好几个模型，新手一般选名字里带「**Flash**」「**Lite**」「**Turbo**」的——便宜、够快、适合练手。
6. **先做最小的一次尝试**：让 AI 回答一句最简单的话，确认能拿到回复，再往上加功能。

> 关键点：**第 3 步的密钥保管**和第 4 步的**额度确认**，是新手最容易出事的地方。

## 新手常踩的坑

- **密钥泄露**：一旦被人拿去刷调用，费用算在你头上。发现泄露就**立刻删除旧密钥、重新生成**。
- **额度悄悄用完**：先设一个**消费上限或提醒**，别等账单出来才惊讶。
- **境外服务连不上**：部分国外平台在国内访问不稳定，优先选**国内服务商**，省掉大量折腾。
- **一上来就做复杂功能**：先跑通「问一句、答一句」，成功后再加记忆、加工具、加流程。

## 它不适合什么

- **只想偶尔问一句**：直接用聊天网页就够了，没必要接 API。
- **完全不想花钱也不想学习**：先玩透现成的 AI 工具，等有明确需求再回来。
