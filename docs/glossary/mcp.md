# MCP

**一句话**：一套统一标准，让 AI 方便地接入各种数据源和工具。

> 英文名：Model Context Protocol · 分类：应用与工具

## 详细解释

由 Anthropic 提出并开源。以前每个 AI 应用都要为每个工具单独写对接，有了 MCP 就像 USB-C 一样统一了接口。

## 举个栗子

装一个 MCP 服务，AI 就能直接读你的本地文件、查数据库、操作设计稿。
