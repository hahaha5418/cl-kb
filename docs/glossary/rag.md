# RAG

**一句话**：先检索你的资料，再让 AI 基于资料回答，能大幅减少幻觉。

> 英文名：Retrieval-Augmented Generation · 分类：应用与工具

## 详细解释

流程：把文档切成块 → 转成向量存起来 → 提问时检索最相关的块 → 塞进上下文让模型回答。这是目前企业用 AI 最主流的方案。

## 举个栗子

把公司 200 页产品手册做成 RAG，员工问「XX 型号保修多久」，AI 能给出准确答案并标注出处。
