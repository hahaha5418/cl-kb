# API

**一句话**：程序之间互相调用的接口，让你在自己的应用里用上大模型。

> 英文名：Application Programming Interface · 分类：基础概念

## 详细解释

你发一段请求（含提示词和参数），服务商返回结果，按 token 计费。这是在网站、App、脚本里集成 AI 的标准方式。

## 举个栗子

写一个 Python 脚本，调用 API 批量把 500 条商品描述改写成营销文案。
