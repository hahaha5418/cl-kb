# RLHF

**一句话**：用人类偏好打分来训练模型，让它回答更符合人的期待。

> 英文名：Reinforcement Learning from Human Feedback · 分类：模型与训练

## 详细解释

先让人类对多个回答排序，训练一个奖励模型，再用强化学习优化。这是 ChatGPT 变得「好用」的关键一步。

## 举个栗子

同样是回答问题，经过 RLHF 的模型会说人话、有礼貌、拒绝危险请求。
