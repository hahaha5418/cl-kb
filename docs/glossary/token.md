# Token（词元）

**一句话**：AI 读写文字的最小计数单位，不等于「一个字」。

> 英文名：Token · 分类：基础概念

## 详细解释

模型会先把文本切成小碎片再处理，这些碎片叫 token。中文大约 1 个汉字 ≈ 0.6~1 个 token，英文大约 4 个字母 ≈ 1 个 token。API 计费、上下文长度、生成速度全都按 token 算。

## 举个栗子

「我喜欢吃苹果」大约 4~6 个 token；一本 10 万字的书大约 10~15 万 token。
