# 扩散模型

**一句话**：文生图模型的主流原理，从一团噪点逐步「洗」出图片。

> 英文名：Diffusion Model · 分类：应用与工具

## 详细解释

训练时学会把加噪的图片还原，生成时从纯噪声开始一步步去噪。Stable Diffusion、Midjourney、DALL·E 都基于此。

## 举个栗子

输入「赛博朋克风格的猫」，模型从随机噪点迭代 20-50 步画出成图。
