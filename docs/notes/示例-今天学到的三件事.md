# 示例：今天学到的三件事

这是一篇示例笔记，告诉我它讲什么就行，AI 会自动帮我补上分类和标签。

## 1. Token 不等于字数

以前我以为一个汉字就是一个 token，实际上中文大概 1 个字 ≈ 0.6~1 个 token，
所以算 API 费用的时候不能按字数直接乘，得留点余量。

## 2. RAG 是企业用 AI 的主流方式

不是把所有资料塞进提示词，而是先检索再回答。这样既省钱又不容易胡说八道。
下次可以试试把我的产品手册做成一个 RAG。

## 3. 温度参数真的会影响结果

同一个问题，温度 0.2 和 0.9 出来的答案完全两种风格。
查事实调低，写文案调高。
