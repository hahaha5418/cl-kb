# Gamma

<Callout type="info" title="一句话看懂">
**输入一句话主题**，直接生成排版精美的 PPT
</Callout>

## 它到底是什么

制作演示文稿，就像拼图一样简单。

## 你能用它做什么

- **制作演示文稿，分享工作成果。**
- **制作教学视频，方便知识传播。**
- **制作产品介绍，吸引潜在客户。**

## 新手实操：一步一步跟着做

<Steps>
<Step title="注册Gamma账号">访问Gamma官网，填写注册信息，创建账号。</Step>
<Step title="选择模板">在Gamma中选择一个合适的演示文稿模板。</Step>
<Step title="编辑内容">在模板中添加文字、图片、视频等内容。</Step>
<Step title="预览并保存">预览演示文稿效果，保存到Gamma账户。</Step>
</Steps>

<Callout type="tip" title="让效果更好的小技巧">

- **使用Gamma的模板库，快速制作专业演示。**
- **利用Gamma的动画效果，使演示更生动。**
- **分享链接或二维码，方便他人观看演示。**
</Callout>

<Callout type="warn" title="新手常踩的坑">

- **免费版功能有限，可能需要付费升级。**
- **演示文稿可能需要在线观看，影响分享。**
- **隐私问题，注意保护演示内容。**
</Callout>

<Callout type="warn" title="它不适合什么">

- 不适用于需要复杂动画和交互的演示。
- 不适用于需要大量数据处理的演示。
</Callout>
