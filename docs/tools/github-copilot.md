# GitHub Copilot

<Callout type="info" title="一句话看懂">
写代码时的**自动补全助手**，边写边给提示
</Callout>

## 它到底是什么

编程时的好帮手，帮你写出更好的代码。

## 你能用它做什么

- **自动补全代码，提高编程效率。**
- **提供代码建议，优化代码质量。**
- **辅助学习编程，理解代码逻辑。**

## 新手实操：一步一步跟着做

<Steps>
<Step title="安装GitHub Copilot插件">在GitHub编辑器中安装Copilot插件。</Step>
<Step title="开始编写代码">在GitHub代码编辑器中开始编写代码。</Step>
<Step title="使用代码补全">在编写代码时，Copilot会自动提供代码补全建议。</Step>
<Step title="选择建议">根据需要选择Copilot提供的代码建议。</Step>
</Steps>

<Callout type="tip" title="让效果更好的小技巧">

- **熟悉Copilot的提示词，提高使用效率。**
- **结合自己的编程风格，调整Copilot的建议。**
- **定期查看Copilot的使用记录，了解自己的编程习惯。**
</Callout>

<Callout type="warn" title="新手常踩的坑">

- **Copilot的建议可能不准确，需要人工审核。**
- **部分功能可能需要付费使用。**
- **过度依赖Copilot可能导致编程能力下降。**
</Callout>

<Callout type="warn" title="它不适合什么">

- 不适用于需要深度定制和优化的项目。
- 不适用于需要严格遵循编码规范的项目。
</Callout>
