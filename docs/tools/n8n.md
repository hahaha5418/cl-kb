# n8n

<Callout type="info" title="一句话看懂">
把各种软件**串起来自动跑**的工作流工具
</Callout>

## 它到底是什么

自动完成一系列重复性工作，节省时间。

## 你能用它做什么

- **自动处理文件**
- **自动化社交媒体发布**
- **集成不同服务**

## 新手实操：一步一步跟着做

<Steps>
<Step title="创建工作流">在平台上创建一个新的工作流，设置开始和结束条件</Step>
<Step title="添加步骤">根据需要添加步骤，比如‘发送邮件’、‘上传文件’等</Step>
<Step title="设置条件">设置每个步骤的条件，比如‘当文件大小超过1MB时’</Step>
<Step title="保存工作流">完成设置后，保存你的工作流</Step>
<Step title="启动工作流">点击启动按钮，工作流开始自动运行</Step>
<Step title="监控状态">在工作流运行过程中，可以监控其状态和结果</Step>
</Steps>

<Callout type="tip" title="让效果更好的小技巧">

- **设计工作流时，考虑清楚每个步骤的目的**
- **使用平台提供的模板可以节省时间**
- **定期检查工作流的状态，确保其正常运行**
</Callout>

<Callout type="warn" title="新手常踩的坑">

- **工作流设计复杂时，可能难以调试**
- **部分功能可能需要付费**
- **不适用于需要人工判断的工作**
</Callout>

<Callout type="warn" title="它不适合什么">

- 不适用于需要高度个性化的工作
- 不适用于需要实时交互的工作
</Callout>
