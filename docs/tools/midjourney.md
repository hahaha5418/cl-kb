# Midjourney

<Callout type="info" title="一句话看懂">
**艺术感最强**的 AI 绘图工具，出图质感高
</Callout>

## 它到底是什么

用文字描述，AI帮你画出想要的图片。

## 你能用它做什么

- **创作艺术作品**
- **设计海报、封面**
- **生成创意图片**

## 新手实操：一步一步跟着做

<Steps>
<Step title="输入描述">在对话框里写清楚你想要的图片内容，比如‘一个梦幻的星空’</Step>
<Step title="选择风格">点击风格选项，选择你喜欢的图片风格，比如‘写实’或‘卡通’</Step>
<Step title="生成图片">点击生成按钮，AI会根据你的描述生成图片</Step>
<Step title="下载图片">图片生成后，点击下载按钮，保存到你的设备</Step>
</Steps>

<Callout type="tip" title="让效果更好的小技巧">

- **描述越详细，图片越符合预期**
- **可以尝试不同的风格和参数**
- **注意版权问题，不要使用他人作品**
</Callout>

<Callout type="warn" title="新手常踩的坑">

- **图片生成可能需要一些时间**
- **生成的图片可能不符合预期**
- **部分风格可能需要付费**
</Callout>

<Callout type="warn" title="它不适合什么">

- 不适用于需要精确尺寸的图片
- 不适用于需要复杂细节的图片
</Callout>
