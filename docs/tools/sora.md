# Sora

<Callout type="info" title="一句话看懂">
OpenAI 的视频生成模型，**画面真实感强**
</Callout>

## 它到底是什么

像魔法一样，帮你生成视频。

## 你能用它做什么

- **快速生成视频，节省时间。**
- **制作创意视频，展示个性。**
- **辅助视频制作，提高效率。**

## 新手实操：一步一步跟着做

<Steps>
<Step title="注册账号">去官网注册个账号，就像开个会员一样。</Step>
<Step title="选择模板">选择一个视频模板，就像选拼图一样。</Step>
<Step title="输入文字">输入你想生成的视频内容，就像写剧本一样。</Step>
<Step title="生成视频">点击生成按钮，等待视频制作完成。</Step>
<Step title="预览视频">预览视频效果，确保满意。</Step>
<Step title="导出视频">导出视频文件，分享给你的朋友。</Step>
</Steps>

<Callout type="tip" title="让效果更好的小技巧">

- **选择合适的模板，提高生成效率。**
- **输入清晰的内容，确保视频质量。**
- **多尝试不同参数，找到最佳效果。**
</Callout>

<Callout type="warn" title="新手常踩的坑">

- **生成视频质量可能不稳定。**
- **隐私设置不当，可能导致信息泄露。**
- **付费功能限制，可能无法满足需求。**
</Callout>

<Callout type="warn" title="它不适合什么">

- 对视频质量要求极高的用户。
- 不熟悉AI技术的用户。
</Callout>
