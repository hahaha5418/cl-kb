# Coze 扣子

<Callout type="info" title="一句话看懂">
**零代码搭 AI 机器人**，还能一键发布到微信、飞书
</Callout>

## 它到底是什么

像搭积木一样，把日常工作变成自动化流程。

## 你能用它做什么

- **自动处理邮件**
- **定时发送消息**
- **批量处理文件**
- **管理日程安排**

## 新手实操：一步一步跟着做

<Steps>
<Step title="注册账号">访问 Coze 扣子官网，注册免费账号。</Step>
<Step title="创建工作流">点击创建工作流，选择要自动化的任务类型。</Step>
<Step title="设置条件">根据任务需求，设置触发条件和执行动作。</Step>
<Step title="保存并运行">检查无误后，保存工作流并启动。</Step>
<Step title="监控状态">工作流运行时，可以实时监控状态。</Step>
<Step title="调整优化">根据运行效果，调整工作流设置。</Step>
</Steps>

<Callout type="tip" title="让效果更好的小技巧">

- **先从简单的任务开始，逐步学习。**
- **利用模板快速创建工作流。**
- **定期检查工作流运行情况。**
</Callout>
