# Dify

<Callout type="info" title="一句话看懂">
开源平台，让你**不写代码搭出带界面的 AI 应用**
</Callout>

## 它到底是什么

像搭积木一样，把重复的工作自动化。

## 你能用它做什么

- **简化重复性工作，节省时间。**
- **提高工作效率，减少错误。**
- **连接不同应用，实现数据互通。**

## 新手实操：一步一步跟着做

<Steps>
<Step title="注册Dify账号">访问Dify官网，填写注册信息，创建账号。</Step>
<Step title="创建工作流">在Dify中创建一个新的工作流，选择要自动化的任务。</Step>
<Step title="配置任务">根据提示，配置任务的触发条件和执行步骤。</Step>
<Step title="保存并运行">保存工作流设置，启动自动化任务。</Step>
</Steps>

<Callout type="tip" title="让效果更好的小技巧">

- **利用Dify的模板，快速开始自动化。**
- **定期检查工作流运行情况，确保正常工作。**
- **学习Dify的语法，自定义更复杂的自动化任务。**
</Callout>

<Callout type="warn" title="新手常踩的坑">

- **自动化任务可能需要一定的设置技巧。**
- **部分高级功能可能需要付费使用。**
- **自动化可能导致数据错误，需谨慎设置。**
</Callout>

<Callout type="warn" title="它不适合什么">

- 不适用于需要人工判断和决策的任务。
- 不适用于需要实时监控和调整的场景。
</Callout>
