# 每日热点详情库 · 手动投放指南

> 这一整套是给「不会写代码」的人用的。你只需要会**复制文件、改文字、保存**。

---

## 一、这个文件夹是干什么的

`data/news/` 里**一个文件 = 一天的热点**，文件名就是日期：

```
data/news/2026-09-10.json   ← 9月10日的所有热点
data/news/2026-09-09.json   ← 9月9日的所有热点
```

网站会自动读取这里所有 `.json` 文件，按日期分组显示。**你丢一个文件进去，网站上就多一天的内容。**

文件名带下划线开头的是参考用的，网站会忽略：
- `_模板.json` —— 空白模板，复制它来写新内容
- 本文件 `README.md` —— 就是你现在看的这份说明

## 二、手动加一条热点（4 步）

### 第 1 步：复制模板
复制 `_模板.json`，粘贴，改名为你要的日期，比如 `2026-09-11.json`。

### 第 2 步：填日期
打开新文件，第一行改成你的日期：
```json
"date": "2026-09-11"
```

### 第 3 步：填内容
`items` 是一个列表，每一条热点是一个 `{...}`。要加第二条，就在第一个 `}` 后面加**英文逗号**，再粘一个 `{...}`：

```json
"items": [
  { ...第一条... },
  { ...第二条... }
]
```

### 第 4 步：告诉我
跟我说一句「**更新网站**」，我会自动重建并发布，一分钟内线上就能看到。

## 三、12 个字段怎么填

| 字段 | 填什么 | 例子 |
|---|---|---|
| `id` | 唯一编号，别重复就行 | `2026-09-11-gpt6-release` |
| `title` | 中文标题 | `OpenAI 发布 GPT-6` |
| `source` | 来源媒体 | `OpenAI 官网` / `量子位` / `TechCrunch` |
| `publishedAt` | 发布时间 | `2026-09-11T09:00:00+08:00` |
| `summary` | 一句话摘要，30-50 字 | `OpenAI 发布 GPT-6，推理能力提升 40%。` |
| `detail` | **详细摘要 200-500 字**：背景、做了什么、为什么重要、对普通人影响 | 见模板 |
| `points` | **关键要点 3-8 条**，每条讲一件不同的事 | `["要点1", "要点2"]` |
| `quotes` | 原文摘录（关键句，别整篇复制） | `{"text": "原句", "note": "为什么重要"}` |
| `image` | 图片路径 | `/covers/news/llm.svg` |
| `url` | 原文链接 | `https://...` |
| `entities` | 涉及的公司 / 模型 / 工具 | `{"companies": ["OpenAI"], "models": ["GPT-6"], "tools": []}` |
| `tags` | 标签 1-3 个 | `["模型发布", "行业动态"]` |
| `advice` | 学习建议：`learn` 今天学什么，`do` 今天做什么 | 见模板 |

**三个字段可以留空**：`quotes`、`entities`、`advice` 不填也不会报错，网站自动隐藏对应区块。

## 五、改错了怎么办（常见 JSON 报错）

写 JSON 最容易犯三个错，记住就不会出问题：

1. **最后一项后面不能有逗号**
   ```json
   ["要点1", "要点2"]     ✅
   ["要点1", "要点2",]    ❌ 多了个逗号
   ```
2. **必须用英文双引号**，不能用中文引号 `“”`
3. **字符串里的双引号要转义**：写成 `\"`。嫌麻烦就直接别在内容里用双引号。

拿不准就把文件发给我，我帮你查。
